# W.VOTE — голосование прямо в чате w.tv

Статический сайт: стример вводит ссылку на свой канал, сайт читает публичный чат w.tv,
зрители пишут слово-голос (`win` / `lose`), сайт считает голоса и ведёт таблицу лидеров.

* Сайт: `https://xiqima.github.io/w-vote/`
* Бэкенда нет, аккаунтов и паролей нет. Все очки, раунды и настройки лежат в `localStorage`
  конкретного браузера.
* Сборки нет: обычные `<script>`, открывается даже двойным щелчком по `index.html`.

## Раунд в три шага

1. **Начать голосование** — зрители пишут слово-голос, голоса считаются.
2. **Остановить приём голосов** — голоса фиксируются (можно «Возобновить»).
3. **Была победа / Было поражение** — угадавшим +1 очко.

Плюс: ручная правка очков, экспорт `.xlsx` (листы «Лидеры», «Раунды», «Сводка») / `.csv` / `.txt`,
резервная копия JSON, история раундов, свои слова-голоса, режим переголосования.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | разметка: экран подключения + рабочая панель |
| `style.css` | оформление, тёмная тема, адаптив |
| `core.js` | логика без DOM: сообщения, голоса, очки, localStorage, **сеть к w.tv**, сборка xlsx |
| `app.js` | интерфейс: рендер, обработчики, опрос чата, экспорт, диагностика связи |
| `config.js` | `window.WTV_DEFAULT_PROXY` — прокси по умолчанию (пусто = только публичные) |
| `optional-proxy/` | свой посредник на Cloudflare Workers (не обязателен) |
| `tests/` | проверки на Node без зависимостей |
